# Gestão de Pedidos

Aplicação simples para gerenciar pedidos utilizando Firebase Firestore.

## Configuração

1. Copie `firebaseConfig.example.js` para `firebaseConfig.js` e substitua pelos seus dados do Firebase.
2. Abra `index.html` em um navegador moderno.

## Desenvolvimento

O projeto utiliza apenas HTML, CSS e JavaScript puro. Para alterar estilos ou comportamento, edite os arquivos na raiz do projeto.
